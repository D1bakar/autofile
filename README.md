# autofile

Watch a folder, sort loose files by type. Dry-run by default — nothing moves
until you say so.

## Why

Files get dumped into `C:\Users\Sayantan\Desktop\Developer` and just sit there.
autofile classifies them by extension and files them into `_sorted/` bins,
stopping at the top level: project folders are never touched.
